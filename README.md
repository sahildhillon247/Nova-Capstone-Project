# Placement Preparation Platform

An all-in-one platform to help students organize their coding practice and track their progress while preparing for software engineering placements.

## Overview

Students preparing for software engineering placements often use multiple platforms for coding practice, learning, and progress tracking. Keeping track of solved problems, identifying completed topics, and understanding overall progress can become difficult when this information is scattered across different tools.

The Placement Preparation Platform aims to simplify this process by bringing coding practice tracking into one place.

The initial focus is to build a useful, simple product that helps students maintain a record of their preparation without requiring them to abandon the coding platforms they already use.

## Problem Statement

Placement preparation often involves disconnected tools and platforms. Students may solve problems on different coding platforms but lack a unified view of their progress.

This can make it difficult to:

- Maintain a consistent record of solved problems.
- Track progress across different topics.
- Review preparation progress in one place.

## MVP&#x20;

The MVP focuses on a core workflow: browsing curated coding problems, recording completed problems, and viewing preparation progress.

### Planned Features

- **User Authentication:** Allow students to create accounts and log in.
- **Curated Problem List:** Browse a collection of coding problems maintained by the platform.
- **Problem Details:** View problem titles, external links, topics, and difficulty levels.
- **Completion Tracking:** Mark problems as solved and record completion details.
- **Progress Dashboard:** View overall completion statistics and topic-wise progress.

Users will continue solving problems on the original coding platforms. The initial version will focus on tracking rather than executing code itself.

## Out of Scope for the MVP

The following features may be considered in future versions:

- Adding custom problems using external links.
- Peer mock interviews and interview scheduling.
- AI-powered interview feedback and personalized recommendations.
- A comprehensive learning-resource library.
- College dashboards for monitoring students' preparation progress.
- Automatic synchronization with external coding platforms.

## Target Audience

College students preparing for their first software engineering placements.

The product may expand to support graduates, working professionals, and other placement candidates in future versions.
